# Security Policy

## Supported Versions

We provide security updates and patches for the active development branch of qVista.

| Version | Supported |
| --- | --- |
| QGIS 3.22+ compatible releases | :white_check_mark: |
| Older releases (< QGIS 3.10) | :x: |

---

## Reporting a Vulnerability

The **Ajuntament de Barcelona** and the qVista team take the security of our software seriously.

If you discover a security vulnerability or potential sensitive data exposure within this repository, please do **NOT** open a public issue.

Instead, please report it responsibly by contacting:
- **Email**: `sit@bcn.cat` (or through the official IT security channels of the Municipal Institute of Informatics - IMI).

Please include in your report:
1. A description of the vulnerability and its potential impact.
2. Steps to reproduce the issue or a proof-of-concept.
3. Any suggested remediations if available.

We will review reports promptly and coordinate any necessary fixes or disclosures.
